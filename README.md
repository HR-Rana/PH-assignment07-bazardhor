# বাজার দর (BazarDor)

## A Daily Market Price Tracking Web Application

BazarDor is a web application that helps users check daily prices of essential products in Bangladesh.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB

## Key Features

1. View daily prices of essential products.
2. Compare current and previous prices.
3. Browse products by category.
4. Register and log in to an account.
5. Access a personal profile after login.
